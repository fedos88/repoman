# 🚀 RepoMan

**Бесплатный open-source менеджер репозиториев с проксированием и кэшированием upstream-источников.**

RepoMan создаётся как лёгкая и современная альтернатива коммерческим и ограниченным Community-решениям для организации локального кэша программных зависимостей и артефактов.

## 🎯 Зачем RepoMan?

Современная инфраструктура постоянно загружает пакеты и артефакты из внешних источников:

- APT-репозитории
- YUM / RPM-репозитории
- npm
- Go Modules
- Docker Registry
- обычные HTTP-файлы

Разработчики, серверы и CI/CD-системы многократно скачивают одни и те же данные.

RepoMan располагается между клиентами и внешними репозиториями.

При первом запросе RepoMan получает артефакт из upstream-репозитория и сохраняет его локально.

Последующие запросы обслуживаются из локального кэша.

Это позволяет:

- уменьшить внешний трафик;
- ускорить CI/CD;
- уменьшить зависимость от доступности внешних сервисов;
- централизовать доступ к внешним репозиториям;
- снизить количество повторных загрузок;
- использовать единый proxy/cache внутри инфраструктуры.

## 🌟 Основные особенности

- 🚀 **Бесплатный и без искусственных ограничений** — без лимитов на количество компонентов, пользователей или запросов
- 🔍 **Proxy & Cache** — автоматическое кэширование артефактов из upstream-репозиториев
- 📦 **Несколько форматов репозиториев** — единая точка доступа для различных package manager'ов
- 🛡️ **Open Source** — исходный код распространяется под лицензией Apache 2.0
- ⚡ **Лёгкое развёртывание** — минимум компонентов и простая конфигурация
- 🐳 **Container-friendly** — возможность запуска в Docker
- 🌍 **Кроссплатформенность** — Linux, macOS и Windows
- 📊 **Готовность к эксплуатации** — метрики, управление кэшем и наблюдаемость
- ⚙️ **Configuration as Code** — возможность описывать upstream-репозитории конфигурацией

## 💡 Основной принцип

RepoMan не стремится быть большой Software Supply Chain платформой.

Основная задача проекта проста:

> **Один локальный сервис для быстрого и надёжного кэширования программных зависимостей.**

```text
            Internet
               │
     ┌─────────┼─────────┐
     │         │         │
    APT       npm      Docker
     │         │         │
     └─────────┼─────────┘
               │
               ▼
          ┌─────────┐
          │ RepoMan │
          └────┬────┘
               │
       ┌───────┼────────┐
       │       │        │
    Jenkins  GitLab  Developers
```

## 🚧 Статус проекта

RepoMan находится на ранней стадии активной разработки.

API, формат конфигурации и внутренняя архитектура могут изменяться до выхода первой стабильной версии.

Проект пока **не рекомендуется использовать в production-средах**.
